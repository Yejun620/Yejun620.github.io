# Yejun Lee | Portfolio

Personal portfolio site built with plain HTML, CSS, and JavaScript. Deployed with GitHub Pages.

**Live site: https://yejun620.github.io**

## Structure

```
index.html
css/style.css
js/main.js
images/profile.jpg
```

## Run locally (for development only)

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000. This address only works on your own computer while the server is running.
